# Equipment Monitor & Shipping Daily Board

공장 설비 점유 현황 모니터링 + 출하 공정 관리 실시간 웹 애플리케이션

## Features

- **실시간 설비 모니터링** — 라인별 장비 점유 현황을 공장 레이아웃에 시각화
- **출하 Daily 보드** — Outlook 메일 자동 파싱 → 출하 공정 추적 (생산관리 → 사전작업 → FQC → 완료)
- **선포장 워크플로우** — 선포장 장비는 14:30에 즉시 배치, 일반 장비는 자정에 배치
- **FQC 알림** — 사전작업 완료 시 담당자에게 실시간 푸시 알림
- **카메라 현황판** — 공용 카메라 사용 상태 실시간 관리
- **자동 리포트** — 일간/주간/월간/분기/반기/연간 리포트 자동 발송
- **자정 스냅샷** — 변경 전/후 보드 스크린샷 자동 촬영 및 메일 발송
- **PWA 지원** — 모바일 홈 화면에 앱처럼 설치 가능

## Tech Stack

- **Backend**: Node.js, Express, Socket.io (실시간 통신)
- **Frontend**: Vanilla JS, HTML/CSS (프레임워크 없이 경량 구현)
- **Auth**: Token 기반 인증 (Bearer)
- **Email**: Microsoft Graph API (Outlook 메일 파싱 + 발송)
- **Screenshot**: Puppeteer-core + Edge headless
- **Process**: PM2 (프로세스 관리, 무중단 운영)
- **Protocol**: HTTPS (자체 서명 인증서)

## Setup

```bash
# 의존성 설치
npm install

# SSL 인증서 생성 (자체 서명)
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365 -nodes

# 서버 실행
node server.js

# PM2로 운영
pm2 start ecosystem.config.js
```

### 필요 설정 파일 (`.gitignore`에 포함, 직접 생성 필요)

| 파일 | 설명 |
|------|------|
| `cert.pem`, `key.pem` | SSL 인증서 |
| `graph-config.json` | Azure AD 앱 설정 (clientId, tenantId, clientSecret) |
| `data.json` | 설비/출하 데이터 (자동 생성) |
| `users.json` | 사용자 계정 (자동 생성) |

## 1. 접속 방법

### PC에서 접속
1. 크롬(Chrome) 브라우저를 엽니다
2. 주소창에 입력합니다: `https://[서버IP]:3443`
3. "연결이 비공개가 아닙니다" 경고가 뜨면 → **고급** → **계속 진행** 클릭

### 핸드폰에서 접속
1. **PC와 같은 WiFi**에 연결되어 있어야 합니다
2. 브라우저에서 `https://[서버IP]:3443` 입력
3. 보안 경고가 뜨면 → **고급** 또는 **세부정보 표시** → **계속 진행** 클릭

> **참고**: `http://` 로 접속해도 자동으로 `https://` 로 이동됩니다

## 2. 핸드폰에 앱처럼 설치하기

앱스토어에서 설치하는 앱이 아니라, 브라우저에서 홈 화면에 추가하는 방식입니다.

### 아이폰 (Safari)

1. **Safari**로 `https://[서버IP]:3443` 접속
   - 반드시 Safari를 사용해야 합니다 (Chrome에서는 안 됨)
2. 보안 경고가 뜨면 **세부사항 보기** → **이 웹사이트 방문** 클릭
3. 화면 하단 가운데 **공유 버튼** 클릭
4. 아래로 스크롤하여 **"홈 화면에 추가"** 선택
5. 이름을 원하는 대로 수정 (예: "출하 Daily")
6. 우측 상단 **추가** 클릭

### 갤럭시 / 안드로이드 (Chrome)

1. **Chrome**으로 `https://[서버IP]:3443` 접속
2. 보안 경고가 뜨면 **고급** → **계속 진행** 클릭
3. Chrome 우측 상단 **점 세 개 메뉴 (⋮)** 클릭
4. **"홈 화면에 추가"** 또는 **"앱 설치"** 선택
5. 이름 확인 후 **추가** 클릭

## 3. 회원가입

1. 접속하면 로그인 화면이 뜹니다
2. 하단 **회원가입** 탭 클릭
3. 아래 정보를 입력합니다:
   - **아이디**: 원하는 아이디
   - **비밀번호**: 원하는 비밀번호
   - **이름**: 본인 이름 (FQC 알림 매칭에 사용되므로 **정확히** 입력)
   - **소속**: 드롭다운에서 선택

> **중요**: 이름은 출하일정 메일의 FQC 담당자 이름과 **동일하게** 입력해야 FQC 알림을 받을 수 있습니다

---

## 4. 로그인

1. 아이디, 비밀번호 입력
2. **로그인** 버튼 클릭 (또는 Enter 키)

## 5. 출하 Daily 화면 구성

### 요약 바
각 공정별 현재 건수를 표시합니다:
- **생산관리** (주황): 생산관리팀이 처리해야 할 건수
- **사전작업** (파랑): 사전작업팀이 처리해야 할 건수
- **FQC** (초록): FQC팀이 포장해야 할 건수
- **완료** (회색): 출하 완료된 건수
- **취소** (빨강): 출하 취소된 건수

### 범례 (색상 의미)
| 셀 색상 | 의미 |
|---------|------|
| 주황색 | 생산관리가 가져가야 할 장비 |
| 파란색 | 사전작업을 해야 할 장비 |
| 초록색 | FQC 포장을 해야 할 장비 |
| 회색 | 완료된 장비 |
| 빨간 점선 테두리 | 출하 취소됨 |
| 보라색 "선" 배지 | 선포장 대상 |
| 회색 ✓ 배지 | 출하 완료 |

## 6. 출하 공정 진행 방법

출하는 아래 순서로 진행됩니다:

```
출하 예정 (주황) → 생산관리 완료 → 사전작업 완료 (파랑) → FQC 완료 (초록) → 출하 완료 (회색)
```

1. 자기 팀 색상의 셀을 찾습니다
2. 해당 셀을 **클릭** (터치)
3. 팝업에서 장비 정보를 확인합니다
4. 작업이 완료되면 **초록색 완료 버튼**을 클릭합니다

## 7. 공정 되돌리기

실수로 완료 버튼을 눌렀을 경우, 자기 팀의 공정만 되돌릴 수 있습니다.

| 소속 | 되돌릴 수 있는 공정 |
|------|---------------------|
| 생산관리 | 생산관리 완료 → 출하 예정으로 되돌리기 |
| 엔티 | 사전작업 완료 → 생산관리 완료로 되돌리기 |
| 산업품질2팀 | FQC 완료 → 사전작업 완료로 되돌리기 |

## 8. 출하 취소 / 취소 복원

### 출하 취소
1. 취소할 장비 셀 클릭
2. 팝업 하단 **"취소"** 버튼 클릭
3. 비밀번호 입력 후 **확인** 클릭

### 취소 복원
1. 취소된 셀 (빨간 점선) 클릭
2. **"취소 복원"** 버튼 클릭
3. 비밀번호 입력 후 **확인** 클릭

## 9. FQC 알림 기능

사전작업(엔티)이 완료되면 해당 장비의 FQC 담당자에게 자동으로 알림이 전송됩니다.

### 알림 받는 조건
- 회원가입 시 입력한 **이름**이 메일의 FQC 담당자 이름과 **동일**해야 합니다
- 출하 Daily 페이지에 **접속 중**이어야 토스트 팝업이 뜹니다

---

## 10. FQC 검색

1. 상단 검색 바에서 FQC 담당자 **이름** 입력
2. 해당 담당자의 장비 셀이 **노란 테두리**로 강조됩니다
3. **초기화** 버튼으로 강조 해제

---

## 11. 설비 모니터링 페이지

공장 설비 점유 현황을 실시간으로 모니터링하는 페이지입니다.

- 접속: `https://[서버IP]:3443/` (로그인 후 기본 페이지)
- 각 라인별 장비 사용 현황을 확인할 수 있습니다

## FAQ

**Q: 접속이 안 돼요**
- PC/핸드폰이 회사 WiFi에 연결되어 있는지 확인하세요
- `https://` 로 시작하는지 확인하세요 (포트 3443)

**Q: FQC 알림이 안 와요**
- 회원가입 시 입력한 이름이 출하일정 메일의 FQC 담당자 이름과 정확히 일치하는지 확인하세요

**Q: 출하 데이터가 매일 초기화되나요?**
- 매일 자정(00:00)에 Outlook에서 당일 출하일정 메일을 자동으로 가져옵니다
