개요 v1.0

출하 Daily는 공장 출하 장비의 진행 상태를 실시간으로 추적하는 웹 애플리케이션입니다. PC와 모바일 모두에서 접속 가능하며, 모든 팀원이 동시에 같은 화면을 보면서 장비 상태를 관리할 수 있습니다.

핵심 기능
• 라인별 출하 장비 현황을 한눈에 확인 (A~M라인, IA~ID라인)
• 단계별 진행 상태 실시간 업데이트 (소켓 통신)
• 부서별 권한에 따른 단계 전환
• FQC 포장 요청 알림
• 출하 검색 (이름, shipment, 고객사 등 복합 검색)NEW
• 카메라 현황판 (FQC · NT 전용)NEW
• 자동 로그인 (체크박스)NEW
• 선포장 즉시 배치 (일반 장비는 자정 배치)NEW
• 슬롯 이동 / 비우기 / 수동 등록 (관리 기능)

라인 배치도

A~E라인, F~I라인, IA~ID라인, J~M라인으로 구성된 공장 배치도입니다. 각 칸이 하나의 장비 슬롯이며, 색상으로 진행 상태를 표시합니다.

A ~ E 라인
각 25슬롯 (1~25번)
F ~ I 라인
F·G: 6~19번 / H·I: 5~19번
IA ~ ID 라인
각 5슬롯 (1~5번)
J ~ M 라인
각 10슬롯 (1~10번)

단계 전환

배치도에서 장비 칸을 터치(클릭)

칸 색상이 자동 변경, 모든 접속자에게 실시간 반영

단계 되돌리기

잘못 전환한 경우, 팝업에 표시되는 "돌아가기" 버튼으로 이전 단계로 되돌릴 수 있습니다. 자신의 부서에 해당하는 단계만 되돌리기 가능하며, 산업품질2팀은 모든 단계를 되돌릴 수 있습니다.

출하 취소 / 복원

취소: 팝업의 "취소" 버튼 → 비밀번호 입력 → 장비가 붉은 점선(취소) 상태로 변경
복원: 취소된 장비의 팝업에서 "취소 복원" → 비밀번호 입력 → 원래 상태로 복원
* 산업품질2팀만 가능

FQC 알림

사전작업이 완료되면(사전작업 완료 → FQC 완료 단계 전환 시) FQC 팀에게 포장 요청 알림이 자동 발송됩니다. 화면 우측 상단의 🔔 종 아이콘에 빨간 배지로 알림 수가 표시되며, 클릭하면 알림 목록을 확인할 수 있습니다.

검색

검색 바에 키워드를 입력하면 해당 장비 위치에 빨간 화살표와 이름이 표시됩니다. FQC 담당자, shipment, 고객사, S/N, tracking 등 다양한 필드를 검색할 수 있으며, 띄어쓰기로 여러 키워드를 입력하면 AND 조건으로 동시에 검색됩니다. "초기화" 버튼으로 검색을 해제합니다.

선포장 즉시 배치 NEW

출하 일정에 "선포장"으로 표시된 장비는 메일 수신 즉시 배치도에 반영됩니다. 일반 장비는 자정에 일괄 배치됩니다.

선포장 vs 일반 장비
선포장 장비
• 메일 수신 즉시 배치
• 보라색 선 뱃지 표시
• 자정에 뱃지 자동 제거
일반 장비
• 자정(00:00)에 일괄 배치
• 기존 출하 데이터 정리 후 배치
• 선포장 뱃지 없음
처리 흐름
출하검사 계획 메일 수신 (Outlook 자동 또는 수동 붙여넣기)
선포장 장비 → 즉시 해당 슬롯에 배치, 보라색 "선" 뱃지 표시
일반 장비 → 다음 날 자정(00:00)에 일괄 배치
자정 배치 시 선포장 뱃지 자동 제거 (상태는 유지)

자동 로그인

로그인 화면에서 "자동 로그인" 체크박스를 체크하면, 다음 접속 시 자동으로 로그인됩니다. PC 브라우저에서 매번 로그인 정보를 입력하는 번거로움을 줄여줍니다.
* 로그아웃하면 자동 로그인 설정이 해제됩니다

접속 및 설치

같은 네트워크(Wi-Fi)에 연결된 PC에서 브라우저를 열고 아래 주소를 입력합니다.

https://서버IP:3443

"안전하지 않음" 경고가 뜨면 "고급" → "안전하지 않은 사이트로 이동"을 클릭하세요.

계정 생성

접속 후 로그인 화면에서 "회원가입" 탭을 통해 계정을 생성합니다.
소속은 생산관리, 엔티, 산업품질2팀 중 선택하며, 소속에 따라 사용 가능한 기능이 달라집니다.
출하 전용 계정(ship)은 별도로 사전 등록되어 있습니다.

"안전하지 않음" 경고가 뜹니다
자체 서명 인증서를 사용하기 때문입니다. "고급" → "안전하지 않은 사이트로 이동"을 클릭하면 됩니다. 이후에는 경고가 뜨지 않습니다.
모바일에서 접속이 안 돼요
서버 PC와 같은 Wi-Fi(또는 같은 네트워크)에 연결되어 있어야 합니다. https://[서버IP]:3443 으로 접속하세요.
버튼이 안 보여요 (단계 전환 버튼 등)
소속(부서)에 따라 표시되는 버튼이 다릅니다. 위 "권한별 기능" 표를 확인하세요.
장비가 잘못된 슬롯에 배치됐어요
산업품질2팀 계정으로 해당 장비를 터치 → "이동" 버튼으로 올바른 슬롯으로 옮기거나, "비우기"로 슬롯을 초기화할 수 있습니다.
톱니바퀴 아이콘이 안 보여요
슬롯 관리(톱니바퀴) 기능은 산업품질2팀 소속 계정에만 표시됩니다.
